# PWA Instructions

An npm package (`pwa-instructions`) of illustrated "install this web app" guides: one SVG and one text guide per platform, browser and layout, with a framework-free core and React components. `examples/react` is the demo published to GitHub Pages. The README describes the package; `docs/` covers the API and releasing.

Stack: ES modules, TypeScript, React, Vite, `node --test`, release-it; Node 24 in CI.

Lifecycle: published to npm (version 0.2.0, tags `v0.1.0` and `v0.2.0`); the demo deploys to GitHub Pages from `main`. The published API and locale modules are a public contract. Release only through `docs/releasing.md` (`npm run release`).

`guides/**/install.svg` and `guides/**/instructions.md` are generated by the build and committed; `npm run check:static` fails when they are stale.

## Commands

| Command | What it does |
| --- | --- |
| `npm ci` | Install from the lockfile. |
| `npm run build` | Check locales, compose the guides, build the package and the example. |
| `npm test` | All tests, serially, one worker. Run `npm run build:packages` first. |
| `npm run check` | Build, typecheck the example, then test. What GitHub Actions runs. |
| `npm run check:static` | Build, typecheck the example, and fail if the committed English guides differ from what the build generates. TeamCity's Static Checks. |
| `npm run test:ci` | Build the package, then the tests with a JUnit report in `test-reports/`. TeamCity's Unit Tests. |
| `npm run check:locales`, `npm run check:labels` | The locale and label checks on their own. |
| `npm run pack:package` | A local npm archive of the package. |

Logs from the build's checks go to `tmp/`.

## CI

- GitHub Actions (`.github/workflows/pages.yml`) runs `npm run check`, checks the committed English guides are current, and deploys the example to GitHub Pages.
- TeamCity (`.teamcity/`) runs Static Checks and Unit Tests under the All Checks composite on every push to `main`, and nightly. Check a build with `python3 scripts/teamcity.py status`.
