# Add to Dock in Safari

Requires macOS Sonoma 14 or later. These illustrations show the File menu route; Safari also offers Add to Dock in its Share menu.

1. **Open the File menu.** Open the website in Safari. In the menu bar at the top of your Mac screen, click File.
2. **Choose Add to Dock.** In the File menu, click Add to Dock. Safari opens a confirmation dialog for this website.
3. **Click Add.** Keep or edit the app name, then click Add. A web app is saved to your Applications folder and added to the Dock.

Open the new app from your Dock.
