# Install an app in Chrome

This guide follows the Chrome menu route shown in the reference screenshots. Some websites also offer an install icon in the address bar.

1. **Open the *More* menu.** Open the website in Chrome. Click the three vertical dots at the top-right of the Chrome window to open the More menu.
2. **Choose *Cast, save and share*.** In the More menu, choose Cast, save and share to open its submenu.
3. **Choose *Install*.** In the submenu, click Install followed by the website or app name. Some versions of Chrome call this item Install page as app. Choose the installation action above Create shortcut; Create shortcut is a separate command.
4. **Click *Next*.** In the Install app dialog, check the website name and domain, then click Next. If your Chrome version goes straight to the Install confirmation, continue to step 5.
5. **Click *Install*.** The next dialog shows the app being added to Chrome Apps. Click Install to confirm.
6. **Click *Show in Finder*.** When Chrome says Successfully installed, click Show in Finder to locate the installed app. You can also choose Open tab in app to open the website in its app window immediately.
