# Add to Home Screen

1. **Open the Page Menu.** Tap the Page Menu button on the left side of the website address bar. Its icon has three horizontal lines, with a shorter bottom line.
2. **Tap Share.** In the Page Menu, tap Share. Its icon is a square with an arrow pointing upward.
3. **Tap View More.** If the share sheet is collapsed, tap View More, shown with a downward chevron, to reveal the remaining actions. If the action list is already visible, continue to step 4.
4. **Tap Add to Home Screen.** In the expanded action list, find and tap Add to Home Screen. Its icon is a rounded square containing a plus sign.

Follow the confirmation screen to finish adding the app.
