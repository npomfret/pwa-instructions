# Install an app in Android Chrome

Use Chrome for Android. The illustrated menu labels follow Google’s current Android help, rather than its older Add to Home screen article. Documentation draft: not yet verified on a device; menu layout and confirmation prompts may vary.

1. **Open the *More* menu.** Open the website in Chrome. Tap the three vertical dots beside the address bar.
2. **Tap *Install and create shortcut*.** Choose Install and create shortcut from the menu. Older Chrome layouts may call this Add to Home screen.
3. **Tap *Install*.** Choose Install. Complete the prompts Chrome displays to install the app. Create shortcut is a separate option that saves a link.
