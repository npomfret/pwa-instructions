# Add to Home Screen in iPhone Safari

1. **Open the Page Menu.** Tap the menu icon beside the website address. It looks like three horizontal lines, with a shorter bottom line.
2. **Tap Share.** Choose **Share** in the Page Menu. Its icon is a square with an arrow pointing upward.
3. **Tap View More.** If the share sheet is collapsed, tap **View More**, shown with a downward chevron. If the action list is already visible, continue to step 4.
4. **Tap Add to Home Screen.** Find **Add to Home Screen** in the expanded action list and tap it. Its icon is a rounded square containing a plus sign.

Follow the confirmation screen to finish adding the app. That screen is not included in the supplied references or illustration.
