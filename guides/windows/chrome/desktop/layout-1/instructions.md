# Install an app in Windows Chrome

Use the Chrome menu route, or the install icon in the address bar when the website offers one. Documentation draft: not yet verified on a device; menu layout and confirmation prompts may vary.

1. **Open the *More* menu.** Open the website in Chrome. Click the three vertical dots at the top-right of the Chrome window to open the More menu.
2. **Choose *Cast, save and share*.** In the More menu, choose Cast, save and share to open its submenu.
3. **Choose *Install*.** In the submenu, click Install followed by the website or app name. Some versions of Chrome call this item Install page as app. Choose the installation action above Create shortcut; Create shortcut is a separate command.
4. **Click *Install*.** Check the app name and website address, then click Install. Follow any further confirmation prompts.
